# 🛡️ Pobynb Custom Adblock Filters

個人專用跨裝置 uBlock Origin / Brave 網頁元素隱藏與自訂過濾清單。

---

## 📡 訂閱網址 (Subscription URL)

請複製下方 RAW 直連網址加入各裝置瀏覽器：

```text
https://raw.githubusercontent.com/pobynb/adblock-filters/main/my-filters.txt
```

---

## ⚙️ 如何在各電腦的 uBlock Origin 訂閱？

1. 點擊瀏覽器右上角 **uBlock Origin 圖示 ➔ 齒輪（進入設定儀表板）**。
2. 切換到上方 **「篩選清單 (Filter lists)」** 分頁。
3. 往下滑到最底部的 **「自訂 (Custom)」** 區塊。
4. 勾選 **「匯入 (Import)」**，將上方訂閱網址貼入輸入框中。
5. 點擊頁面最上方的 **「套用變更 (Apply changes)」**。

---

## 🔄 自動同步機制

* 本清單已宣告 `! Expires: 1 days`，uBlock Origin 每日會自動向 GitHub 檢查並拉取最新規則。
* 隨時在本地或 GitHub 新增規則並 `git push` 後，所有訂閱該清單的裝置均會自動生效。
